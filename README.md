\# Задание 5: Сборка и интеграция



\## Описание

Проект содержит модуль приоритизации заявок, обернутый в веб-сервер (Flask), упакованный в Docker-контейнер. Настроен простой пайплайн CI/CD для запуска тестов и сборки.



\## Требования

\- Python 3 (для локального запуска тестов)

\- Docker и Docker Compose (должны быть запущены)



\## Как запустить пайплайн (сборка + тесты + интеграция)

1\. Откройте терминал (или командную строку) в папке проекта.

2\. Выполните скрипт:

&#x20;  - Для Windows: дважды кликните по файлу `build.bat` (или введите `build.bat` в консоли).

&#x20;  - Для Mac/Linux: выполните `chmod +x build.sh`, а затем `./build.sh`.

3\. Скрипт автоматически прогонит тесты, соберет Docker-образ и запустит интеграционный тест.



\## Как проверить работу API вручную

1\. Запустите сервер: `docker-compose up -d priority-api`

2\. Отправьте тестовый запрос (Windows PowerShell):

&#x20;  `curl.exe -X POST http://localhost:5000/api/v1/prioritize -H "Content-Type: application/json" -d '{\\"tier\\":\\"STANDARD\\", \\"urgency\\":\\"HIGH\\", \\"problem\_type\\":\\"ACCESS\\"}'`

3\. Остановите сервер: `docker-compose down`
